# DBD Defender

Project landing page vanilla HTML, CSS, dan JavaScript.

## Cara jalanin
1. Buka `index.html` langsung di browser.
2. Atau jalankan lewat local server sederhana.

## Struktur
- `index.html`
- `styles.css`
- `app.js`
- `assets/`

## Catatan video Laboratorium Nyamuk
Di `app.js`, isi:
- `LAB_VIDEO_TYPE = 'youtube'` lalu set `LAB_VIDEO_SOURCE` ke link embed YouTube
- atau `LAB_VIDEO_TYPE = 'local'` lalu set `LAB_VIDEO_SOURCE` ke file video di folder `assets`

Contoh YouTube embed:
`https://www.youtube.com/embed/VIDEO_ID`
